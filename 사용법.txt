파일 검색과 정리

Windows x64에서 start.cmd를 여세요. 소스에서 실행할 때 필요한 Python과 Node.js 버전은 README.md에 있습니다.

1. 첫 화면에서 파일이나 폴더 이름을 입력하면 이름과 경로가 바로 표시됩니다. Everything 1.5가 실행 중이면 전체 색인을 사용합니다. 직접 탐색한 경우에는 검색한 위치와 한도가 표시됩니다.
2. ‘파일 정리하기’에서 정리할 폴더를 고르세요. 다운로드 폴더도 제외할 수 있습니다. 최소 신뢰도 슬라이더의 설명을 보고 기준을 정하세요.
3. ‘기존 폴더 활용’은 관련 있는 파일을 이미 만들어 둔 폴더에 추가합니다. ‘새 폴더로만 정리’는 이번 파일들을 새 폴더로 묶습니다. 두 방식 모두 선택한 폴더 바로 아래의 파일만 이동 대상으로 삼습니다.
4. ‘분석 시작’을 누르면 검토 화면 상단에 선택한 경로가 나옵니다. 경로를 펼쳐 전체 목록을 확인하세요. 왼쪽에서 묶음을 선택하면 이름의 근거를 볼 수 있고, 파일을 누르면 소속을 정한 이유가 나옵니다.
5. ‘이동 경로 미리보기’에서 각 파일의 원래 경로와 목적지를 확인한 다음 이동을 확정하세요. 새 폴더의 기본 위치는 첫 선택 경로입니다. ‘이동 되돌리기’로 파일을 복원할 수 있습니다.

브라우저 다운로드 출처를 추가하려면 ‘분석 설정 → 추가 분석 옵션 → 브라우저 출처 연결’을 여세요. 브라우저 연결 절차는 README.md에 있습니다.
