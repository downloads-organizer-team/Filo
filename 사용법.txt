실행과 시연

Windows x64 PC에서 ZIP을 폴더에 풀고
start.cmd를 두 번 클릭하세요. 이 PC에서는 ‘실행’ 바로가기를 열어도 됩니다.

일반 파일은 앱을 열면 바로 분석합니다. 다운로드한 웹페이지의 출처도 기록하려면 왼쪽 아래 ‘분석 설정 → 브라우저 출처 연결’을 누르세요. Edge 또는 Chrome의 확장 관리에서 개발자 모드 → 압축 풀린 파일 로드 → 앱이 복사한 폴더를 선택합니다. 출처를 기록할 HTTPS 웹페이지에서 확장 아이콘 → ‘이 사이트 연결’을 누르고 권한을 허용한 뒤 새로고침하세요. 조선대 e-Class는 기본 연결됩니다. 다음 다운로드부터 ‘다시 분석’ 후 파일 행을 눌러 기록된 페이지 제목과 출처 주소, 확인 가능한 강좌명을 볼 수 있습니다.

1. 앱을 열면 내 Windows 다운로드 폴더를 바로 분석합니다. 왼쪽에서 그룹을 선택하면 해당 자료와 추천 근거가 표시됩니다.
   ‘강의 표지로 과목명 찾기’가 켜져 있으면 강의소개·OT의 PDF 첫 페이지 또는 PPTX 첫 슬라이드에서 과목명을 찾습니다. 강의소개 자료가 없으면 1주 1차시 PPTX의 첫 슬라이드를 확인합니다.
   그룹을 선택하면 이름의 근거가 보입니다. ‘파일명 변경’에서 실제 수강 과목명으로 수정해 저장할 수 있습니다.
2. ‘애매한 파일만 본문 분석’을 끄고 ‘다시 분석’을 눌러 1차 결과를 봅니다.
3. 새로 받은 파일은 ‘다시 분석’으로 반영합니다. 다운로드 안의 하위 폴더도 분석하려면 ‘하위 폴더 포함’을 켜세요.
4. ‘유사도 행렬’에서 파일 쌍을 선택하면 1차 점수와 최종 점수를 비교할 수 있습니다.
5. ‘그룹 편집’에서 소속·이름을 바꾸거나 병합·분리하세요. 파일 쌍의 관계는
   행렬 아래의 ‘같은 그룹’과 ‘다른 그룹’으로도 저장할 수 있습니다.
6. ‘파일 검토’에서 오른쪽 위 ‘폴더로 정리’를 누르고 미리보기 오른쪽 아래 ‘○개 파일 이동’을 선택하세요.
   다운로드 안에 그룹 이름별 폴더가 생기고 파일이 이동합니다. 미분류 파일은 그대로 둡니다.
   한 그룹만 정리하려면 그룹 카드를 열고 ‘이 그룹 정리’를 누르세요. ‘최근 이동 되돌리기’로 원래 위치를 복원할 수 있습니다.

다시 열면 현재 다운로드 폴더를 새로 분석합니다. 자세한 설계, 신뢰도 기준, 모듈 구성,
다운로드 문맥 모델, 테스트 실행 방법은 같은 폴더의 README.md에 있습니다.
