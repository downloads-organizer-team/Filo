파일 검색과 정리

Windows x64에서 start.cmd를 여세요. 소스에서 실행할 때 필요한 Python과 Node.js 버전은 README.md에 있습니다.

1. 첫 화면에서 이름을 입력하세요. Everything 1.5가 준비되면 입력한 이름으로 결과가 표시됩니다. 이름 글자를 빠르게 두 번 클릭하거나 Tab과 Enter를 사용하면 폴더는 탐색기에서 열리고 파일은 기본 앱으로 열립니다.
2. ‘파일 정리하기’에서 정리할 폴더를 고르세요. ‘관련 작업별’은 파일명과 다운로드 단서를 비교합니다. ‘확장자별’은 같은 확장자의 파일을 모읍니다.
3. ‘기존 폴더 활용’은 관련 있는 파일을 이미 만들어 둔 폴더에 추가합니다. ‘새 폴더로만 정리’는 이번 파일들을 새 폴더로 묶습니다. 두 방식 모두 선택한 폴더 바로 아래의 파일만 이동 대상으로 삼습니다.
4. ‘분석 시작’을 누르면 이동 가능한 추천 파일이 모두 선택됩니다. 폴더 행의 빈 곳을 눌러 파일을 확인하세요. 제외할 폴더나 파일의 체크를 해제하세요.
5. 선택한 폴더 수와 파일 수를 확인하고 ‘파일 이동’을 누르세요. 목적지를 먼저 보려면 ‘이동 경로 미리보기’를 누르세요. 새 폴더의 기본 위치는 첫 선택 경로입니다. ‘이동 되돌리기’로 파일을 복원할 수 있습니다.

파일 검색과 정리 트리에서 이름 글자를 한 번 누르면 항목을 선택합니다. 선택한 이름을 잠시 뒤 다시 누르거나 F2를 누르면 이름을 바꿀 수 있습니다. Enter를 누르면 기존 파일과 폴더의 이름이 디스크에서 즉시 바뀝니다. Esc로 취소할 수 있습니다. 제안된 새 폴더는 이동을 확정할 때 만들어집니다.

브라우저 다운로드 출처를 추가하려면 ‘분석 설정 → 추가 분석 옵션 → 브라우저 출처 연결’을 여세요. 브라우저 연결 절차는 README.md에 있습니다.
